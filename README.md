# シフト自動作成ツール (LINE連携)

スタッフがLINEで送ったシフト希望を**自動で読み取り**、**自動で返信**し、
集まった希望から**シフト表を自動作成**して、LINEで全員に配信するツールです。

Python 3.10 以上だけで動きます (追加のライブラリは不要)。

## できること

| 誰が | LINEで送る内容 | Botの動き |
|---|---|---|
| スタッフ | `11/3 9-17` `11/5 休み` など | 希望を読み取って保存し、「受け付けました」と内容を自動返信 |
| スタッフ | `確認` | 自分が出した希望の一覧を返信 |
| スタッフ | `取消 11/3` | その日の希望を削除 |
| スタッフ | `シフト` | 確定した自分のシフトを返信 |
| 管理者 | `シフト作成` | 希望をもとにシフトを自動作成し、人手不足の枠と各自の勤務時間を返信 |
| 管理者 | `シフト表` | 作成したシフト表を返信 |
| 管理者 | `公開` | スタッフ全員に、それぞれのシフトをLINEで個別送信 |
| 管理者 | `未提出` / `催促` | 未提出者の確認 / 未提出者へLINEでリマインド |
| 自動 | (設定した日時) | 未提出者へ自動リマインドし、管理者に報告 |

月の指定は `シフト作成 12月` のように付けられます。省略すると「翌月」が対象です。

### 読み取れる希望の書き方

```
11/3 9-17            → 9:00〜17:00 OK
11月5日 休み          → 休み (×, NG, 不可 なども可)
11/7, 11/8 終日       → 終日OK (○, OK, 可 なども可)
11/10〜11/12 早番     → 3日間とも早番OK (config.json のシフト名)
15日 18時から         → 18:00〜閉店まで
20日 15時まで         → 開店〜15:00
11/3(火) ９：３０～１７：００  → 全角・曜日付きでもOK
```

- 1行に複数書いても、複数行に分けてもOKです。
- **送らなかった日は「出勤できない日」**として扱います。
- 同じ日をもう一度送ると上書きされます。

### シフト自動作成のルール

1. 人が集まりにくい枠から先に埋める
2. その月の勤務時間が少ない人を優先して、公平に割り振る
3. 「早番しか入れない人」など融通がきかない人を、その枠に優先して入れる
4. 週の勤務日数・勤務時間の上限、1日1シフトを守る
5. 埋まらなかった枠は「人手不足」として管理者に報告

## セットアップ

### 1. LINE公式アカウントを用意

1. [LINE Developers](https://developers.line.biz/) で「Messaging API」チャネルを作成
2. 「チャネル基本設定」の **チャネルシークレット** と、「Messaging API設定」の
   **チャネルアクセストークン(長期)** をメモ
3. LINE Official Account Manager の応答設定で **「応答メッセージ」をオフ**、**「Webhook」をオン**

### 2. 設定ファイルを作る

```bash
cp .env.example .env              # LINEのシークレット・トークン・合言葉を書く
cp config.example.json config.json  # シフトの種類・必要人数などを書く
```

`config.json` の主な項目:

| 項目 | 内容 |
|---|---|
| `shift_patterns` | シフトの種類と時間 (例: 早番 09:00-14:00) |
| `requirements` | 必要人数。`default` → 曜日 (`mon`〜`sun`) → `dates` (特定日) の順で優先 |
| `day_start` / `day_end` | 「18時から」「15時まで」で使う営業時間 |
| `max_days_per_week` / `max_hours_per_week` | 1人あたりの週の上限 |
| `collect_month` | 希望を集める月 (`next`=翌月 / `current`=今月) |
| `reminder` | 自動リマインドする日 (`days`) と時刻 (`hour`) |

### 3. 起動

```bash
python3 -m shiftbot serve
```

インターネットから届くURLで公開し (レンタルサーバー、Render、Railway、Cloud Run など。
お試しなら ngrok でも可)、LINE Developers の **Webhook URL** に
`https://あなたのドメイン/callback` を設定して「検証」を押します。

### 4. 使い始める

1. スタッフにLINE公式アカウントを友だち追加してもらう (LINEの表示名で自動登録されます。
   `登録 山田太郎` で名前を変更可能)
2. 店長はLINEで `管理者登録 <ADMIN_PASSCODE>` と送って管理者になる
3. スタッフが希望を送る → 店長が `シフト作成` → `シフト表` で確認 → `公開`

## パソコンからの操作 (任意)

```bash
python3 -m shiftbot generate --month 11   # シフト作成
python3 -m shiftbot show --month 11       # シフト表を表示
python3 -m shiftbot export --month 11     # Excelで開けるCSVを exports/ に保存
python3 -m shiftbot publish --month 11    # 全員にLINEで送信
python3 -m shiftbot remind --month 11     # 未提出者にリマインド
python3 -m shiftbot staff                 # スタッフ一覧
python3 -m shiftbot admin 山田太郎         # 管理者にする
```

ブラウザでは `https://あなたのドメイン/shifts?month=11&token=<WEB_TOKEN>` で表形式のシフト表、
`/shifts.csv?month=11&token=<WEB_TOKEN>` でCSVをダウンロードできます。

## テスト

```bash
python3 -m unittest discover -s tests -t .
```

## 注意

- LINEの無料プランはプッシュメッセージ (公開・リマインド) の月間送信数に上限があります。
  自動返信 (リプライ) は無料で無制限です。
- データは `shiftbot.db` (SQLite) に保存されます。定期的にバックアップしてください。
